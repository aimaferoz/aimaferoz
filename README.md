A Python-based Windows desktop assistant that recognizes double-clap gestures and automatically launches a personalized workspace.

**Highlights**
- Real-time audio processing and adaptive clap detection
- Application and browser automation
- ElevenLabs text-to-speech integration
- Multi-monitor window management
- Local speech caching

**Built with:** `Python` `NumPy` `SoundDevice` `Windows API` `ElevenLabs`
